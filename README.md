
# E-Commerce Sales Analytics

## Project Overview
This project analyzes e-commerce sales data using SQL Server and Power BI.

## Tools Used
- SQL Server
- Power BI
- Power Query
- DAX

## Tables
- Customers
- Products
- Orders
- OrderDetails

## Power BI Dashboard
- Total Sales
- Total Orders
- Total Quantity
- Average Sales
- Monthly Sales Trend
- Sales by Category
- Top 5 Products by Sales
- Sales by Customer
- Interactive slicers for Date, Category, and City
